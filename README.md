# Liri

更好的状态栏歌词

![](https://github.com/user-attachments/assets/08661601-f9ee-4158-b9a9-c4a3bd04420b)

Liri 通过系统通知读取权限和悬浮窗，在左上角显示当前音乐的歌词。应用界面和设置页使用基于 Miuix 的 Couix 的组件，支持浅色和深色主题，并采用青绿色作为主题色。

## 功能

- 读取系统媒体通知和媒体会话，识别当前正在播放的音乐；视频内容不会触发歌词搜索。
- 支持 Telegram 等通过媒体会话提供播放信息的应用，并优先选择当前处于播放状态的媒体通知。
- 在悬浮窗中显示当前歌词和下一句歌词，支持切入切出动画、横向滚动、当前句进度条和文字替换。
- 歌词解析精确到毫秒，支持全局歌词偏移和每首歌曲独立偏移。
- 使用网易云音乐接口搜索歌词，支持搜索结果切换和手动重新搜索。
- 当前歌曲已有本地歌词时优先加载本地文件，不会自动覆盖本地歌词；搜索结果需要手动选择。
- 显示专辑封面、歌曲名、艺术家、当前歌词、下一句歌词和搜索结果。
- 支持正则替换、去除假名标注、全角空格转半角以及常见简体字转日文汉字。
- 提供本地 LRC 编辑器，支持替换标签、添加标签、删除标签、批量格式化、撤销、重做和保存。
- 支持自动保存歌词、清空本地歌词以及覆盖保存已有文件。

## 权限

首次使用时，请在“授予系统权限”页面按需授予以下权限：

- **通知读取权限**：读取媒体通知和媒体会话，识别当前播放歌曲。
- **悬浮窗权限**：显示悬浮歌词。
- **忽略电池优化**：减少后台服务被系统停止的可能。
- **通知权限**：Android 13 及更高版本用于应用自身的系统通知。
- **所有文件访问权限**：用于精确读写 `/sdcard/Music/Liri` 中的 LRC 文件。

部分国产系统还需要在系统设置中允许 Liri 自启动或后台运行。若通知读取权限无法授予，请先在应用信息中允许受限权限，再重新打开通知读取权限。

## 歌词文件

歌词文件保存在：

```text
/sdcard/Music/Liri/
```

文件名格式为：

```text
歌曲名 - 艺术家.lrc
```

文件始终使用 `.lrc` 后缀。保存时会自动创建目录；已有同名文件会直接覆盖。清空本地歌词会生成空白文件，使该歌曲以后不会自动搜索歌词。

应用支持 LRC 的 `offset` 标签。全局偏移用于统一调整显示时间，每首歌曲的偏移可在首页“正在播放”区域单独调整，并会写回对应 LRC 文件。

## 首页设置

“位置与样式”包含以下设置：

- **左边界**：悬浮窗距离屏幕左侧的距离。
- **Y 坐标（上边距）**：按屏幕高度百分比设置，范围为 `0.0%` 至 `10.0%`，步长为 `0.1%`，适配横屏和不同屏幕高度。
- **宽度**：悬浮窗宽度，最小值为 `100dp`，最大值为当前屏幕宽度。
- **字号**：悬浮歌词字号。
- **有其它通知时右移**：存在系统非媒体、非静默通知时，将歌词悬浮窗向右移动指定距离，同时等量缩小宽度。
- **每个通知额外右移**：每增加一条符合条件的通知，额外向右移动指定距离，同时等量缩小宽度。
- **切入角度**：以 15 度为步长调整歌词切入切出方向，默认从下方切入，即 180 度。
- **切入距离**：调整动画的起始距离。
- **歌词偏移**：调整全局歌词时间偏移。
- **切入切出持续时间**：调整歌词切换动画时长。

位置与样式的修改会立即应用到悬浮窗。

## 歌词搜索与编辑

搜索关键词默认使用：

```text
歌曲名 歌手名
```

首页“歌词编辑”分组提供自动保存歌词、编辑本地歌词和清空本地歌词。“手动搜词”分组提供关键词输入框、搜索按钮、清空按钮和搜索结果列表。搜索过程中会显示“正在搜索歌词…”，搜索完成或出错时会通过 Toast 提示结果。

本地歌词编辑器使用内置 Maple Mono 等宽字体显示文本和时间标签。编辑器支持：

- **替换标签**：清空当前行时间标签，替换为当前播放进度。
- **添加标签**：在当前行时间标签末尾添加当前播放进度。
- **删除标签**：清空当前行时间标签。
- **批量操作**：格式化歌词或清除所有时间标签。
- **保存**：保存 LRC 文件并提示保存成功。

格式化会应用当前歌曲偏移、移除 `offset` 标签、按时间排序时间标签，并保留只有时间标签的空白歌词行；标题、歌手等其它元信息标签会被移除。

## 文字替换

文字替换始终在显示层执行，不修改本地歌词文件。支持：

- 添加正则匹配串和替换串，替换串可以为空。
- 取消假名标注：去除半角括号内的平假名或片假名。
- 全角空格改为半角。
- 常见简体字转日文汉字。该转换基于公开的简日汉字对照表，因上下文不同可能带来错误。

## 构建

项目使用较新的 Android 工具链：

- Android Gradle Plugin 9.1.0
- Gradle 9.3.1
- Kotlin 2.2.21
- Compose UI 和 Couix/Miuix 组件
- compileSdk 37
- minSdk 26

使用 JDK 21 构建 debug APK：

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@21 ./gradlew :app:assembleDebug
```

生成文件位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 已知限制

- 媒体信息和播放进度取决于播放器提供的通知与媒体会话质量。
- 网易云接口可能因访问频率过高触发临时限制。
- 部分系统会限制通知读取服务、悬浮窗或后台运行，需要在系统设置中额外允许。
